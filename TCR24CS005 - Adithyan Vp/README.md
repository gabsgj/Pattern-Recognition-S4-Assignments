## 📌 Project Description
This project implements a Hidden Markov Model (HMM) using the Baum-Welch Algorithm in C.

The Baum-Welch algorithm is an Expectation-Maximization algorithm used to train HMM parameters:
- Transition Matrix (A)
- Emission Matrix (B)
- Initial State Probabilities (π)
