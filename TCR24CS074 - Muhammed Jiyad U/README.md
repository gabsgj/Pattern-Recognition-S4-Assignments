## Overview
This repository contains a visual implementation of a Hidden Markov Model trained using the Baum-Welch algorithm. It features a web-based UI built with Streamlit, where users can define an observation sequence, specify the number of hidden states, and visually generate the corresponding State-Transition Diagram.

## How to Run the Program

To run this application locally on your machine, follow these steps:

1. **Clone the repository:**
   Open your terminal and run:
   `git clone <paste-your-github-repo-url-here>`

2. **Navigate to the project directory:**
   `cd <your-repo-name>`

3. **Install the required dependencies:**
   Make sure you have Python installed, then run:
   `pip install -r requirements.txt`

4. **Run the application:**
   `streamlit run app.py`
